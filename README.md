
# 1337b04rd

Анонимный имиджборд — проект, вдохновлённый форумами и досками объявлений конца прошлого тысячелетия. Это приложение позволяет пользователям создавать треды с изображениями, оставлять комментарии, анонимно общаться и наслаждаться олдскульной атмосферой.

## 🚀 Описание проекта

- Без регистрации: идентификация через куки.
- Пользователи получают аватар и имя из Rick and Morty API.
- Можно прикреплять изображения к постам и комментариям.
- Посты и комментарии отображаются по таймеру, с удалением неактивных.
- Используется **Hexagonal Architecture (Порты и Адаптеры)**.
- Хранение данных — PostgreSQL.
- Хранение изображений — S3-совместимое хранилище (например, MinIO).
- Логирование — через `log/slog`.

## 📁 Архитектура

Применяется **Hexagonal Architecture**:

- **Domain Layer** — бизнес-логика (создание постов, комментариев, управление сессиями).
- **Adapters**:
  - PostgreSQL (для хранения постов, комментариев, сессий)
  - S3/MinIO (для загрузки и получения изображений)
  - Rick and Morty API (для получения аватаров и имён)
- **Handlers (UI)**:
  - HTTP маршруты, шаблоны HTML
  - Middleware для сессий и куки

## 🧠 Возможности

- Создание постов с изображением и текстом
- Комментирование постов и ответов на комментарии
- Уникальные имена и аватары для пользователей через API
- Удаление постов без комментариев через 10 минут
- Удаление постов с комментариями через 15 минут без активности
- Архив удалённых постов
- Отображение тредов в виде плиток (каталог)
- Использование куки для идентификации пользователей
- Безопасная работа с изображениями

## 🛠 Технологии

- Язык: **Go**
- База данных: **PostgreSQL**
- Хранилище файлов: **S3/MinIO**
- Внешний API: **Rick and Morty API**

- Шаблоны HTML: `catalog.html`, `archive.html`, `post.html`, и др.

## 🧁 Cookie & Сессии

- Каждому пользователю при первом заходе выдаётся уникальный аватар и имя (из Rick and Morty API).
- Информация хранится в зашифрованной cookie на 7 дней.
- При превышении числа доступных аватаров они могут переиспользоваться.

## 🔐 Валидация изображений

- Размеры и типы файлов проверяются при загрузке.
- Обработка загруженных изображений безопасна и устойчива к ошибкам.

## 💬 Шаблоны интерфейса

- `catalog.html` — список активных тредов (без аватаров)
- `archive.html` — все посты, включая удалённые
- `post.html` — подробный вид поста с комментариями
- `archive-post.html` — только просмотр удалённого треда
- `create-post.html` — форма создания нового треда
- `error.html` — обработка ошибок

## 📝 Логирование

- Используется стандартный `log/slog`.
- Уровни логов: Info, Warn, Error и т.д.
- Примеры логов:
  - Успешное создание поста
  - Ошибка загрузки изображения
  - Неудачное подключение к БД

## 🧠 Примечания

- Нельзя использовать внешние библиотеки (кроме драйвера PostgreSQL).
